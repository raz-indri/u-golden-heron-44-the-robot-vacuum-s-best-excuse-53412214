A one-line excuse from a robot vacuum for missing a spot: its cliff sensor mistook the rug fringe for a canyon, so it braked hard enough for its own dustbin to file a complaint.

> I didn't miss that spot — my cliff sensor saw the rug fringe, screamed 'canyon!', and I braked so hard my dustbin filed a complaint.

Contract: `main.py` writes exactly one line of at most 140 characters to `entry.txt`.
